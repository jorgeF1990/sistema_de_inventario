# Sistema de Control de Stock v2.0.0

Sistema profesional de gestión de inventario desarrollado en Python con interfaz gráfica Tkinter y base de datos MySQL.

## 📋 Características

- ✅ Gestión completa de productos (ABM)
- ✅ Control de stock con entrada/salida automática
- ✅ Registro de ventas con actualización de stock
- ✅ Reporte de movimientos con filtros por fecha y tipo
- ✅ Reporte de ventas por periodo
- ✅ Productos más vendidos
- ✅ Alertas de stock bajo
- ✅ Exportación a CSV
- ✅ Interfaz profesional y responsiva

## 🛠️ Tecnologías

- **Python 3.x** - Lenguaje principal
- **Tkinter** - Interfaz gráfica
- **MySQL** - Base de datos
- **mysql-connector-python** - Conector MySQL
